# Событие `change`. Как реагировать на выбор в списке

Вы уже читали значение `<select>` через `.value` после нажатия кнопки. Теперь список сам будет запускать обработчик, когда пользователь выберет другой пункт.

## Как связать подпись со списком

`<label>` — подпись к полю. Текст внутри тега объясняет, что нужно выбрать. Атрибут `for` связывает подпись с конкретным полем. Его значение должно совпадать с `id` этого поля.

```html
<label for="floor">Этаж</label>
<select id="floor">
  <option value="1">Первый этаж</option>
</select>
```

Здесь `for="floor"` указывает на список с `id="floor"`. Благодаря этой связи программа чтения с экрана может прочитать «Этаж» как название списка. Если поменяете `id`, обновите и `for`.

## Как работает `change`

Раньше вы добавляли обработчик `click` к кнопке. Теперь добавьте обработчик `change` к самому `<select>`. Внутри обработчика прочитайте `.value` списка. Там уже будет значение нового пункта.

При открытии страницы событие `change` само по себе не срабатывает. Поэтому начальный текст можно сразу написать в HTML.

## Пример. Выбор этажа

Сохраните пример в `example.html` и откройте его в браузере. Выберите третий этаж, затем второй. Под списком по очереди появятся «Вы выбрали этаж 3» и «Вы выбрали этаж 2».

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Выбор этажа</title>
</head>
<body>
  <label for="floor">Этаж</label>
  <select id="floor">
    <option value="1">Первый этаж</option>
    <option value="2">Второй этаж</option>
    <option value="3">Третий этаж</option>
  </select>

  <p id="result">Вы выбрали этаж 1</p>

  <script>
    const floor = document.getElementById('floor');
    const result = document.getElementById('result');

    floor.addEventListener('change', () => {
      const selectedFloor = floor.value;
      result.innerHTML = 'Вы выбрали этаж ' + selectedFloor;
    });
  </script>
</body>
</html>
```

Например, пользователь видит в списке «Третий этаж», а `floor.value` возвращает строку `'3'` из атрибута `value`.

## Задание. Афиша кинотеатра

Сделайте страницу `index.html` с заголовком «Афиша кинотеатра». Пользователь выбирает фильм из списка и сразу видит его обложку, название и описание. При смене фильма все три элемента обновляются в той же карточке.

### 1. Добавьте список и карточку первого фильма

Рядом с `index.html` создайте папку `covers` и положите в неё три изображения в формате JPG. Можно взять любые подходящие картинки и назвать их `space.jpg`, `house.jpg` и `train.jpg`.

Возьмите заготовку и допишите два пункта по таблице. При открытии страницы уже выбран первый фильм, поэтому его данные сразу указаны в HTML.

```html
<label for="movie">Фильм</label>
<select id="movie">
  <option value="space">Космическая станция</option>
</select>

<div>
  <img id="poster" src="covers/space.jpg" alt="Обложка фильма «Космическая станция»" width="200">
  <h2 id="title">Космическая станция</h2>
  <p id="description">Команда астронавтов получает загадочный сигнал.</p>
</div>
```

| Название фильма | Значение `.value` | Путь к обложке | Описание |
| --- | --- | --- | --- |
| Космическая станция | `space` | `covers/space.jpg` | Команда астронавтов получает загадочный сигнал. |
| Тайна старого дома | `house` | `covers/house.jpg` | Друзья находят письмо, спрятанное под половицей. |
| Поезд на север | `train` | `covers/train.jpg` | Пассажиры знакомятся во время поездки через заснеженные горы. |

### 2. Обработайте выбор

1. Найдите список, картинку, заголовок и абзац через `getElementById()` или `querySelector()`.
2. Добавьте обработчик `change` к списку. Для первой проверки выведите `movie.value` в абзац. При выборе «Тайна старого дома» должно появиться `house`.
3. Через `if / else if / else` определите, какой фильм выбран. Сначала обновите название и описание через `innerHTML`. Затем обновите картинку через `.src` и её текстовое описание через `.alt`.

Например, в ветке для фильма «Тайна старого дома» можно обновить картинку так:

```js
poster.src = 'covers/house.jpg';
poster.alt = 'Обложка фильма «Тайна старого дома»';
```

### 3. Проверьте в браузере

1. Откройте страницу. В списке выбрана «Космическая станция», под ним видна карточка этого фильма.
2. Выберите «Тайна старого дома», затем «Поезд на север». При каждом выборе сразу меняются обложка, название и описание.
3. Вернитесь к «Космической станции» и проверьте, что все три элемента снова относятся к первому фильму.
